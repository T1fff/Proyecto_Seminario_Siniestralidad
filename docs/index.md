# Modelación Predictiva de la Siniestralidad en Seguros de Automóviles

**Un Análisis Comparativo entre Modelos Lineales Generalizados (GLM), Algoritmos de
Machine Learning y Redes Neuronales**

Seminario investigativo — Ciencia de Datos aplicada al sector asegurador.

## Estado actual del proyecto

Esta primera entrega contiene:

1. **[Análisis Exploratorio de Datos](../notebooks/01_Analisis_Exploratorio_Datos.ipynb)**
   — inspección estructural, calidad de datos y caracterización general de la cartera
   `freMTPL2`.
2. **[Análisis Univariado](../notebooks/02_Analisis_Univariado.ipynb)** — distribución,
   dispersión e interpretación actuarial variable por variable.

Las etapas siguientes de la investigación (análisis bivariado/multivariado,
preprocesamiento, y modelación mediante GLM, Machine Learning y redes neuronales) se
incorporarán en entregas posteriores. Ver `README.md` en la raíz del repositorio para el
contexto completo de la investigación.
